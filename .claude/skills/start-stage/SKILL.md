# 段階を始める手順

**この手順ではコードを書かない。** 設計案を出して、持ち主の判断を待つところまで。

1. **依頼を読む**：依頼書（`stageNN-prompt.md`）があれば全部。無ければ持ち主の依頼と CLAUDE.md の「これからの方針」
2. **今の状態を読む**：PROGRESS.md は「次にやること」「実機で未確認のこと」だけ（ほかの段の記録は読まない）
3. **関係する仕様を読む**：CLAUDE.md の「機能ごとの仕様の場所」から、この段階で触る機能の `.claude/rules/*.md`。画面を変えるなら DESIGN.md のいちばん上
4. **コードを調べる**：`rg` で関係するファイルを絞ってから読む。広く調べるときは Explore のサブエージェントに任せ、要点だけ受け取る
5. **設計案を出す**（持ち主はプログラミング初心者。専門用語は短く補う）：
   - 何ができるようになるか（持ち主の使い方の言葉で）
   - 画面の流れ（どの画面で、何を押すと、何が出るか）
   - データの形が変わるか（変わるなら：版・古い形の読み方・バックアップに入れるか）
   - 小分けにするなら、その分け方（それぞれの終わりで報告して止まる）
   - **判断してほしいこと**：1 つずつ、選択肢・おすすめ・その理由
6. 止まって待つ。了承を得たら実装に入る（締めは `/finish-stage`）
