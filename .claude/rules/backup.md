# データを守る・まとめてのバックアップ（段階17）

> CLAUDE.md から移した仕様（2026-11-24）。この機能の仕様を変えたら、このファイルを直す。
> 下のパスのファイルを読んだときだけ読み込まれる。

- **データを守る（段階17、v0.41.0〜、持ち主の依頼書 stage17-prompt・判断 2026-11-23「おすすめの通りで」。`src/storage/persist.ts`・`src/storage/backup.ts`・`src/tree/backupFile.ts`・`src/app/DataSection.tsx`）**：
  - データの保護：`navigator.storage.persist()` を、アプリを開いたとき（研究手順かツリーが 1 つでもあるとき）と、研究手順を保存したとき（開いている間に 1 回）に呼ぶ。守られていれば何もしない。
    設定の「データ」に「守られています／守られていません／この端末では確かめられません」。守られていなければ説明（ホーム画面に追加すると守られやすい・ときどきバックアップを）と［守るように頼む］
  - まとめてのバックアップ：設定の［バックアップを保存］で、研究手順・ツリー（用意済みのコピーも）・復習の記録（ツリーと研究手順）・自分で登録した戦型・設定を 1 つの JSON
    （`{ app: 'joban-tree', kind: 'backup', version: 1, createdAt, appVersion, data: { studies, trees, reviews, templates, prefs } }`。後から games・practice・positions・deleted を足した、ファイル名 `将棋定跡帳-バックアップ-2026-11-23-1305.json`）。
    共有の画面（使えなければダウンロード）。iPhone/iPad は押した直後でないと共有を断るので、ファイルの中身は設定の画面を開いたとき（と設定を変えたとき）に作っておく
  - 設定（`prefs`）に入れるのは localStorage の `joban-tree.settings`・`joban-tree:book-write`・`joban-tree.home-collapsed`・`joban-tree.hints-seen`・`joban-tree.recent`（`PREF_KEYS`）。アプリの中だけの記録は入れない
  - **あとから種類を足せる**：段階18 の実戦の棋譜などは `data` に種類を足すだけ（`version` は 1 のまま。`KNOWN_KINDS` に足し、読み書きを足す）。この版が知らない種類のあるファイルは、戻せるが「それは入りません」と知らせる。
    形の違う新しい `version` のファイルは「新しい版のアプリで作ったバックアップです」と断る
  - 戻す（置きかえるだけ。足すはしない）：ファイルを選ぶ → 形を確かめる（ツリー・研究手順・戦型は今の取り込みと同じ確かめ方、復習の記録・設定は `backupFile.ts`。1 つでもおかしければ全体を読まない）→
    中身の数を見せて「今のデータを全部置きかえる」→ **戻す前のデータを端末の中に取っておく**（別の IndexedDB `joban-tree-before-restore` に最新の 1 回分。今の保存場所の形は変えない）→
    4 つの保存場所を 1 つのトランザクションで空にして書く → アプリを読み込み直す。設定の［戻す前のデータに戻す（日時）］で元に戻せる（戻すとまた今のデータが取っておかれる）。ツリーの生成中は戻さない
  - 最後にバックアップした日（localStorage `joban-tree.last-backup`。共有の画面で保存先を選び終えたとき・ダウンロードを始めたときに書く）を設定に出す。
    研究手順が 1 本以上あり、最後のバックアップ（まだなら、いちばん古い研究手順を作った日）から 30 日以上なら、定跡帳の一覧の上に「しばらくバックアップしていません［設定で保存］［×］」。
    閉じたら 30 日は出さない（`joban-tree.backup-nudge-hidden-until`）
- **ほかの端末のバックアップを合わせる（段階22-2、v0.50.0〜、持ち主の依頼と判断 2026-11-26「全部おすすめの通りで」。合わせ方は `src/tree/merge.ts`、印は `src/tree/deleted.ts`、消した記録の置き場所は `src/storage/deleted.ts`、確認の中身は `src/app/MergeSummary.tsx`）**：
  - 設定の「データ」の［ほかの端末のバックアップを合わせる］→ ファイル → この端末で変わる数（種類ごとの 足す・新しくする・消す）と消える研究手順の名前・枝分かれで両方残す数 →［合わせる］→ 読み込み直す。合わせる前のデータは「戻す」と同じ所に取っておく。ツリーの生成中は合わせない。「戻す（全部置きかえる）」は今まで通り
  - **研究手順**（順に）：① 同じ id で、手順が続き（短くした形）でない（別々に枝分かれ）→ **両方残す**。片方の新しい id は分かれた手から決まる（どの端末でも同じ。稽古の記録はその手順に付いていく）。
    ② 同じ id は 1 本：**手順は長い方**。短い方が勝つのは、長い方の手が全部「消したときに見ていた手順」（`cutFrom`）の中で、消した日時（`cutAt`）が長い方の手の変更（`movesAt`、無ければ `updatedAt`）より後のときだけ（見ていない手は消さない。1 手試して取り消した場合も）。依頼の案の「後で手を変えた方」は、消していない手が消えるので変えた（持ち主に報告）。この端末で短くなる研究手順は、確認の窓に名前と手数。
    名前・戦型・側は後で直した方（`updatedAt` と `restoredAt` の新しい方）。**メモは後でメモを直した方**（`noteAt`。同じ日時ならもう片方を含む方）。作った日時は古い方。
    ③ 手順と側が同じで id が違うものは 1 本。**残す id は作った日時が古い方**（端末の id を残すと、いつまでもそろわず、手を延ばしたときに重複する）。稽古の記録を付け替える。**メモは両方残す**（`――` でつなぎ、区切りごとに 1 回ずつ。つないだメモの日時は新しい方）。
    **同じ端末に元から両方ある 2 本は 1 本にしない**（取り込みの「両方残す」など。メモが 20000 字を超えるときも分けたまま）。重複の片方を消した記録は `onlyId`（同じ id だけに効く）。同じ端末に同じ手順の別の研究手順があるものは、id が違う消した記録では消さない。消した記録は、手順でまとめる前に当てる
    - 枝分かれの新しい id が、改名する側にすでにある id・相手の続きでない研究手順の id なら、さらに別の id にする
    - 片方で手を消してから別の手を足すと「枝分かれ」になり、消した枝が別の研究手順として残ることがある（消えるより安全）
  - **消した記録**（`data.deleted`。localStorage `joban-tree.deleted`。**捨てない**）：研究手順・実戦・戦型・ツリー・復習の記録（消す）・局面メモ（空にした）・候補の表の手（外した）。研究手順は手順と側も持つ。
    消した日時が相手の最後に直した日時より新しければ消す。**研究手順は、同じ id なら消した版に全部の手が入っているときだけ**（見ていない手は消さない）、id が違えば手順と側がまったく同じときだけ
  - **保存するときの印**（保存の関数の中で付ける。`stampStudy`・`stampPosition`）：研究手順の `movesAt`（手を変えた）・`restoredAt`（直した日時が前に戻る＝取り消し・置き換え、または消したものをもう一度保存）。
    `updatedAt` は変えない（並び順はそのまま）。局面の記録は `noteAt` と候補の手ごとの `at`。実戦の `updatedAt`・`restoredAt`、戦型・ツリーの `restoredAt`
  - **戻す・戻す前のデータに戻す**：消した記録のあるものを戻すときは戻した日時を付けて、その記録を消す（`reviveForRestore`。復習の記録も。前の「このままでよい」は表の形にする）。合わせると相手にあるものはまた入る（窓に書く）
  - **中身が変わらない合わせ（`changesNothing`）では「戻す前のデータ」を取り直さない**。ツリーは中身（後で直した方）と名前（後で名前を直した方。`renamedAt`）を別々に合わせる。古いファイルでの置き換えは `restoredAt` を付ける
  - **今の決まりで残っていること**：まとめた id（旧 → 残す）は覚えないので、まとめる前の端末でその手順を延ばすと、短い版と長い版の 2 本になる。実戦の消した記録は id だけ（同じ実戦を別々に貼って、片方を消しても、もう片方は戻る）。
    悪手にして切った研究手順を相手が延ばしていると、研究手順は残り、候補の表は悪手のまま。候補の表が 8 手を超えると、古い手は出さずに落ちる。消した記録がどこにも無い状態で古いファイルから復活させたものは、相手の消した記録で消える。この版より前に消した手は、まだ長い版を持つ端末と合わせると一度戻る
  - 局面の記録：局面メモと候補の表は別々。表は手ごとに新しい方、本命が 2 つなら後で付けた方（ほかは次善）、8 手を超えたら本命・新しい順に残す
  - 稽古の記録は `lastAt` が新しい方。実戦・戦型・ツリーは id ごとに新しい方（同じ中身の実戦は先に貼った方の id の 1 局）。復習の記録は問題ごとに新しい方。**設定は合わせない**
  - DB の版・バックアップの版は変えていない。足した項目は全部任意（古いバックアップは「消した記録なし」で読める。古いアプリは「消した記録は入りません」で戻せる）
