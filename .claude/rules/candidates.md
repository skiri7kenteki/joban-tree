# 自分の手の候補表（段階21）

> この機能の仕様を変えたら、このファイルを直す。下のパスのファイルを読んだときだけ読み込まれる。

- **目的と小分け（持ち主の依頼 2026-11-25）**：自分の手番の局面ごとに「本命・次善・悪手」の表。**文字を打たなくても全部使える**こと。研究手順は 1 本道のまま、データの形も変えない。
  21-1（v0.47.0）表・定跡帳・エンジンに聞く・食い違い・バックアップと KIF → 21-2 悪手の咎め方を盤でたどる・稽古の次善/悪手 → 21-3 見えにくい手。それぞれの終わりで報告して止まる
- **データ**：局面の記録（`positions`。`positions.md`）の任意の項目 `candidates`（8 手まで）。`{ move, mark: 'main'|'alt'|'bad', eval?（自分の側から）, by?: { engine, ms, at }, pv?（その手を指した後。10 手まで）, hard?（21-3）, reason?（200 字まで） }`。
  本命は 1 局面に 1 つ。DB の版もバックアップの版も変えない。形は `candidatesProblem`（指し手は文字の形だけ確かめる）。
  前の `okMoves` は読むときに次善（本命は、その中の研究の手でいちばん最近直した研究手順の手。`tableOf`）。次に表を書くときに `candidates` へ移る
- **相手の手番には表を持たせない**（局面メモは相手の手番にも書ける）
- **画面の数は本命との差**（`markText`。本命が無ければ表の中のいちばん良い点との差。次善が本命より良ければ「+40」。詰みは「（詰み）」「（詰まされる）」）
- **自動の印（`mergeResults`。持ち主の判断 2026-11-25「すべておすすめの通りで」）**：研究の手のうちいちばん良いものが本命（研究の手が無ければエンジンの最善）。本命との差が設定の `thresholds.goodMax` 以下なら次善、超えたら悪手。**研究の手は、悪くても自動では次善まで**。
  「研究の手」はこの局面の研究の自分の手すべて（手順前後・ほかのグループも。`studyMovesAt`）
- **もう一度残す**：表の手も一緒に調べ直して点と読み筋を新しくする。**手・印・理由は残し**、自動の印は新しい手にだけ（表に本命が無く、本命にするはずの手が表にあれば、本命なしのまま）。確認してから。
  8 手を超える分は入れない（表の手 → 本命 → 指した手 → 研究の手の順に残し、入らなかった数を出す）
- **盤で指して調べる**（持ち主の判断：自然に見える悪手はエンジンの上位 3 手に入らないので）：候補の窓・［エンジンに聞く］の窓の［ほかの手を盤で指して調べる］→ 見出しの行が「調べる手を盤で指す［やめる］」→ 指すと（足さずに）エンジンの窓が開き、その手も調べる（「指した手」）。局面が変わるとやめる
- **研究手順が通る手を悪手にする**：確認の窓（消える研究手順・この局面で終わる形で残る研究手順の名前）→ その手から先を消して（手順前後も。`cutMoveAt`）から表を保存。1 回で取り消せる
- **悪手の印のある手は、盤で指しても［足す］でも研究手順に足さない**（知らせを出す）。棋譜を貼る・取り込み・基本の研究は今は確かめない
- **画面**：定跡帳の行に印の札（`.mark-tag`。本命＝墨、次善＝木の茶、悪手＝朱。**行の札は言葉だけ**で、本命との差は行の ⋯ の窓と候補の窓に。段階23）。研究手順の無い表の手は薄い行「研究手順なし」（押すと候補の窓）。行の ⋯ の窓に「本命・次善・悪手・表から外す」と理由（打ちたいときだけ）。
  見出しの行：表かメモがあれば小さなボタン「候補・メモ」（相手の手番は「メモ」。メモがあれば ✎。**中身は出さない**。段階23）／どちらも無ければ何も出さない。メモを新しく書くのは ⋯ の「この局面」→「候補・局面メモ」（相手の手番は「局面メモ」）。
  **見出しの行の高さ・盤の大きさは変えない**
- **咎め方を盤でたどる（21-2、v0.48.0。局面の並びは `refutation`）**：研究手順の無い悪手の行（読み筋があるもの。行の右は「咎め方を見る ›」）を押すと、盤が悪手を指した局面になる。操作バーは「咎め方 n／N手」で ‹ ›・|‹ ›|・左右スワイプ。盤では指せない。
  一覧の枠は「咎め方を見ています［戻る］」・悪手と印・読み筋の並び・理由（見出しの行の高さは一覧と同じ。［戻る］は見た目 32px で押せる範囲は 44px）。局面が変わる・悪手の印が無くなると終わる。研究手順には入れない。開くときは一覧の枠をいちばん上へ。見ている間は盤の大きさを変えない。
  読み筋の無い悪手の行は候補の窓。研究手順が通っている手の行は、悪手の印があっても今まで通り研究手順へ進む。稽古の扱いは `practice.md`
- **見えにくい手（21-3、v0.49.0）**：自分の手番でエンジンに聞くと、深い読みの前に「すぐの最善」を調べる（`engine.clearHash()`＝`isready` で前の読みの記憶を消してから、0.1 秒・候補 1 つ。`ASK_SHALLOW_MS`）。
  順番が逆だと、深い読みの記憶で同じ手が出る。その手が候補に無ければ、点を比べるためだけに調べる（一覧と表には出さない。`shallowOf`）。
  - 印の付け方（`mergeResults` の `shallow`）：調べた手ごとに、すぐの最善と違っていて、深い読みの点がすぐの最善の手より `thresholds.goodMax` を**超えて**良ければ `hard`。**使うのは本命のときだけ**（`hardMove`。本命を付け替えても調べ直さずに合う）。浅い読みが分からないときは前の印のまま。もう一度残すと付け直す
  - 出す所：［エンジンに聞く］の窓の本命になる行と候補の窓の本命に「見えにくい」の札（`.hard-tag`）、下に「「見えにくい」は目安です：エンジンの浅い読みでは見つからない手。」。定跡帳の行には出さない（狭いスマホで名前が切れるため）。KIF にも出さない
  - 0.1 秒で読める量は端末で違うので、印は端末や回で変わることがある（目安）。稽古の扱いは `practice.md`
- **取り消し**：表の変更も定跡帳の「取り消す」で戻る（局面メモは今のまま）。表の保存は読み書きの切り替え（読むだけ）に関係なくできる
- **KIF の書き出し**：局面のコメントに「候補：▲２四歩（本命）、…」（`candidatesKifLine`）。悪手は変化にしない
