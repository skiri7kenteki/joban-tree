## その2　theme_color を今の地の色にする（アプリの変更。version を上げる）

- `public/manifest.webmanifest` の `theme_color` と `index.html` の `<meta name="theme-color">` を、紺の `#1c2740` から今の地の色 `#f7f5f1`（`--color-bg`）にする
  - 理由：Android でホーム画面から開いたときの上の帯・Chrome の上の帯がこの色になる。今は明るい画面の上に紺の帯が出て「藍は使わない」（DESIGN.md「画面の決まり」2）と合わない
  - manifest と index.html は CSS 変数を使えないので値を直に書く。DESIGN.md の「アイコン」の節に「`theme_color` は `--color-bg` と同じ値。地の色を変えたらここも直す」と書く（「直すのは別の作業」の文は消す）
- iPhone の `apple-mobile-web-app-status-bar-style` は `black-translucent` のまま触らない。
  明るい地の上で上の時刻・電池が見えにくいかどうかは持ち主が iPhone で確かめ、見えにくければ別の依頼にする（変えると画面の上の余白が変わるため）
- 確かめること：`npm run build` が通る・`npx vitest run tests/unit/rules.test.ts`・Playwright は `e2e/one-screen.spec.ts` だけ（test-runner に任せる）
- `package.json` の version を上げる（0.61.1 の案）。`/finish-stage` の手順で締めて報告する
- 報告の「スマホ・iPad での試し方」：Android はホーム画面から開いて上の帯が明るい色か。iPhone はホーム画面から開いて上の時刻・電池が見えるか（見えにくければ教えてもらう）
