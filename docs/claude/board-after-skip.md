# 修正の依頼：早送りの後に、狭いスマホで盤が少し縮む（v0.59.0）

2026-11-27 に持ち主が会話に貼った依頼の控え（番号なし。「早送りの後の盤の直し」）。設計案で止まらず、直して `/finish-stage` で報告する。

## 起きていること（クラウドの Claude が Linux の Chromium で確かめた）
- `e2e/phase26.spec.ts` の 360×640 の早送りのテストが、クラウドの Linux では毎回落ちる。手元の Windows と GitHub Actions では通っている
- 早送りが終わって自分で指し始めたとき、`practice-board` の高さが 384.6px → 367.1px に縮む
- 下の札の「相手は ▲3七桂。ここから指します。」が 360px 幅で 2 行に折り返し、札が高くなった分、盤が小さくなる。字の幅は字体で変わるので、持ち主の Android でも起こりうる
- 段階26 の決まり「盤の大きさは変えない」に反する。指そうとした所がずれる

## 直し方の案（小さな判断は任せる）
- 札の文が 1 行でも 2 行でも盤の大きさが変わらないようにする（早送りの間と同じ行の数にする／札の高さをそろえる）
- 盤の画面を 1 画面に収める決まり・盤の大きさの決まりは変えない

## 確かめること
- phase26 の 3 つの大きさのテストが通る。字体で結果が変わらないように、360×640 で札の文が 2 行に折り返す場合も確かめる
- 稽古のほかの場面（はじめての手・まちがえた後・終わり）でも、札の文の長さで盤が動かないか、360×640 の写真で見る
- version を上げる（0.59.1 の案）

## 直したこと（原因と結果）
- 札はいつも最低 96px で、その中に入るのは 2 行まで。360×640 の盤の下の余白は 1px だけなので、どこかが 1 回折り返すと（まちがえた後の札も同じ）盤が縮み、同じ研究手順の間は戻らなかった
- 文は変えず、稽古の札の上下の余白・段落の間・行の高さを詰めて、3 行でも 96px に収めるようにした（`.practice-card`）
- 手元の Windows でも、テストの中で改行を差し込むと同じ 384.625px → 367.125px になることを確かめてから直した
